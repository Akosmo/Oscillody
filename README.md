# Oscillody
- - -
## Real-time oscilloscope-based audio visualizer
- - -
Oscillody is a free and open-source video creation application developed by [Akosmo](https://akosmo.carrd.co) specifically made for audio visualization.
Audio files can be imported and a visualizer created with multiple types of Elements available for use. The resulting visualizer can be exported as a video, and used in any way.

## How and why it was built
- - -
Oscillody is a passion project of mine. I've always liked audio visualization, but couldn't find cheap or free applications to make those for my videos. The concept likely started in April 3, 2024, from a curiosity of building an audio visualizer with the [Godot Engine](https://godotengine.org). on April 13 of the same year, I started a small prototype to see what's possible. On April 30, during its development, I had the idea of a video creation application. Previously, the only idea I had in mind was of a music player.
On June 4, I had the actual idea for Oscillody, and tried to implement anything that it needed in my prototype to see if that idea would work. In July 5, 2024, I started developing Oscillody.
Oscillody is my first program ever (at least of reasonable size), and also serves as learning ground for future video-game projects.

## Free, open-source, and 100% human-made.
- - -
This is a free and open-source project distributed under the GPL-3.0-or-later versions. You're free to take a look at the code, fork it, and make suggestions on the GitHub repository, however, I'm not accepting code contributions (pull requests) at the moment.
To be clear, the license applies to the application itself only, including code and assets. The videos you make with it are not under that license.
Oscillody is also completely made without generative AI. All the code I have written and all the assets that have been made for it, were made by me. While I can't know for sure how third-party code were written, I kept code not written by me to a minimum, and refused to implement anything that appeared to be generated by AI.
